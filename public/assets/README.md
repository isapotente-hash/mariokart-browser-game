# Assets

Original drivers, vehicles, four procedural courses, battle arena, items and audio are generated from source. The additional Electrodrome course uses a user-supplied GLB. See [its attribution and adaptation details](tracks/README.md). The model is loaded lazily through the configured application base; textures are embedded in the file. Fonts are supplied by the device.

The home screen uses the user-supplied `51697-menu-Mario-Kart-8-Deluxe.jpg`, copied unchanged to `menu/home-screen.jpg`. HTML buttons over the artwork open the actual local game modes. The supplied image's characters, branding and watermark are retained.
