Gameplay adaptation: scaled to game units, positioned relative to the start straight, with authored road navigation, checkpoints, item placement, full 3D magnetic driving, a directed glider launch and a visible magnetic return connector. The original model also includes an alternative colored branch; the playable route follows the authored primary circuit. Mirroring reflects the whole model and gameplay route.

The model downloads only when selected. Low quality hides distant city meshes. Navigation is regenerated by node scripts/import-electrodrome.mjs; the generated data and return connector are game code, separate from the supplied model.
