# Items

`Inventory.ts` owns two-slot capacity, draw delay and automatic reserve promotion. `ItemWorld.ts` implements all eight release items with stable pickup IDs, cooldowns, swept/3D collision, owner grace, warning/target guidance, defensive priority and a fixed transient pool. Human and AI item use share the same rules. Typed definitions and weighted eligibility live in `src/data/items.ts`; shared limits live in `src/data/config.ts`. Time Trial disables random boxes and the race supplies exactly three boosts. Release tests cover all item interactions, opening restrictions and race-wide use.
